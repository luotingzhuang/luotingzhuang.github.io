# Luoting Zhuang — personal site

This site uses the [Minimal Mistakes](https://github.com/mmistakes/minimal-mistakes) Jekyll theme and deploys with GitHub Pages.

## Update points

- Edit `index.md` for the short bio.
- Edit `_pages/publications.md` for the publication list.
- Add a current CV PDF and a navigation link when ready.
- Navigation lives in `_data/navigation.yml`.
